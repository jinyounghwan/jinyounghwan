# 안녕하세요, 백엔드 개발자 진영환입니다.

Java와 Spring을 기반으로 백엔드 시스템을 개발하고 운영해왔습니다.

단순히 기능을 구현하는 데서 끝나지 않고  
데이터 흐름, 외부 시스템 연동, 배치 처리, 운영 환경까지 함께 고민합니다.

## Tech Stack

**Backend**  
Java · Spring · Spring Boot · MyBatis · JPA

**Database**  
Oracle · MySQL · MariaDB · MSSQL

**Integration**  
REST API · External API · Batch · Scheduler

**Server / Infra**  
Linux · Nginx · Apache · Tomcat · JEUS

**Frontend**  
JSP · Thymeleaf · JavaScript · jQuery

## Experience

- 제조 시스템 mEMS / mMES 개발 및 운영
- 외부 전자서명 API 연동
- 이커머스 주문 / 배송 Batch 개발
- 전자세금계산서 및 ERP 연동
- 서버 운영 및 장애 대응
